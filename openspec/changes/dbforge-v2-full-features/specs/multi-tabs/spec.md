# Spec: Multi-Tabs

## ADDED Requirements

### Requirement: 打开新标签页
用户可以打开多个标签页，每个标签页可以是表查看或查询。

#### Scenario: 打开表标签页
- **Given** 用户在表列表中双击某个表
- **Then** 创建新标签页显示该表数据
- **And** 标签页标题为表名

#### Scenario: 打开查询标签页
- **Given** 用户点击"新建查询"按钮
- **Then** 创建新标签页显示空 SQL 编辑器
- **And** 标签页标题为"查询 N"

### Requirement: 标签页切换
用户可以在多个标签页之间切换。

#### Scenario: 点击切换
- **Given** 存在多个标签页
- **When** 用户点击某个标签
- **Then** 切换到该标签页的内容

#### Scenario: 关闭标签页
- **Given** 用户点击标签页的关闭按钮
- **Then** 关闭该标签页
- **And** 自动切换到相邻标签页

#### Scenario: 关闭当前标签
- **Given** 只有一个标签页
- **When** 用户关闭该标签
- **Then** 显示空状态，提示"请选择一个表或创建查询"

### Requirement: 标签页管理
用户可以管理标签页（重置顺序、全部关闭等）。

#### Scenario: 右键菜单
- **Given** 用户右键点击标签
- **Then** 显示菜单：关闭当前、关闭其他、关闭全部

#### Scenario: 标签页溢出
- **Given** 打开超过 10 个标签
- **Then** 标签栏可以横向滚动
- **Or** 显示左右箭头按钮切换视图
